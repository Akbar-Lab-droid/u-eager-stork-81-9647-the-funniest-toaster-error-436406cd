Entry for the [The Funniest Toaster Error Message](https://make.fun/bounty/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd) bounty on make.fun.

The task: write one line, at most 120 characters — the error message a kitchen toaster shows its owner when something goes wrong. It should read like a real message on a real appliance and make someone laugh. The entry text lives in `entry.txt` and is judged pairwise by a house judge in blind rounds.

## How to run

```sh
python3 main.py
```

This copies `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `out/entry.txt`).

## Entry

> ERROR 404: Bread not found. It left to pursue a career in crumbs. Please insert toast that believes in itself.
